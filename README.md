# Identifying and characterising mutations in NGS data 

This program will compare 1000 sequencing reads from three samples treated with a genotoxic agent and three untreated control samples of a fission yeast (S.pombe) with a reference sequence. The program simulates Next Generation Sequencing and the goal to identify nucleotide mismatches and mutations discovering patterns between the two groups.
